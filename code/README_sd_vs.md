# SD 记录和 VS 上位机

按提供的 `sd卡图像存储.zip` / `VS上位机.zip` 接入，保留 `sd_card`、`my_imagetransfer`、`hdu_dma` 的入口。没有新增队列或卡格式管理。

本车摄像头是 188×120，因此保留完整图像，不裁成示例的 186×70。二值图压成 2820 字节，每帧在 SD 上占 8 个扇区：6 个图像扇区、1 个参数扇区、1 个三线扇区。串口帧仍是示例的 `01 02 03 04 05 06 07 08` 开头，50 个参数、1 个保留固定参数，每行 4 字节线数据。

SD 接线引用 `board_pins.h`：SPI1、SCLK P10.2、MOSI P10.3、MISO P10.1、CS P11.11。导出用下载器 UART0：P14.0 TX、P14.1 RX、640000、8N1；导出结束恢复原串口 115200。

## 记录

1. 插入专用 SD 卡，上电后到 `TOOLS`，选择 `SD INIT`，确认 `SD READY=1`。
2. 选择 `SD RECORD`，再按原来的流程 RUN / FOLLOW START。每次 SD RECORD 都从第 0 扇区开始覆盖上一轮记录。
3. 运行中按约 100 ms 间隔记录二值图、当前三线和参数；SD 写入由 CPU1 同步完成，与原示例方式一致，实际帧率受卡写入速度影响。
4. 使用原来的 STOP 停车，记录会停止；也可以选 `SD STOP`。`SD SAVED` 是本次已写入的帧数，`SD ERROR=1` 表示初始化或读写失败。

与原示例一样，这是原始扇区存储，没有 FAT 文件系统。请用无须保留文件的专用卡；记录会覆盖分区/文件内容。帧数仅保存在本次上电的 RAM 中，因此应当保持供电，停车后直接导出，不能先断电再用本程序自动找回帧数。

## 导出

1. 打开 `E:\Workspace\shoucuo\host_vs\MyNrf.sln`，上位机源码已配置为摄像头组、串口二值图模式、640000 波特率、188×120 数据。
2. 连接下载器 USB 串口，在上位机“检测串口”后选实际 USB COM，打开串口，再点“写入缓存”。
3. 小车完全 STOP 后，在 `TOOLS` 选择 `SD EXPORT`。`SD EXPORTED` 达到 `SD SAVED` 即导出完成；导出期间不允许 RUN/FOLLOW/电机测试。
4. 在上位机点“写入数据”，保存到 `E:\Workspace\shoucuo\host_vs\captures`。时间戳子目录包含 `Project.hdu`、原图、拟图和参数文本。以后打开该 `Project.hdu` 可回放。

原 ZIP 的 `SmartProcess` 是另一套固定 186×70 的算法，未用它替换本车算法。这里只回放车上记录的三线和图像。

本次按要求不继续编译、运行或烧录；ZIP 自带的旧 EXE 不包含本次源码修改。
