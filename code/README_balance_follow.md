# 双轮直立、编码器稳速与摄像头循迹

## 控制链路

- ICM42688 每 2 ms 读取一次，传感器输出率为 1 kHz。加速度角由当前 X/Z 轴配置计算，俯仰角速度使用扣除标定零偏后的 Y 轴。
- 姿态采用互补滤波：`angle = Ka_effective * accel_angle + (1 - Ka_effective) * (last_angle + gyro_rate * 0.002)`。菜单与 Flash 的 `ACC WEIGHT KA` 保留原 5 ms 定义，应用参数时换算为 `Ka_effective = 1 - (1 - Ka)^0.4`；原值 0.01 对应约 0.004012，保持滤波时间常数，换算不在每次中断里执行。
- 直立控制每 2 ms 使用直接 PD：`PWM = BALANCE KP * (COMP ANGLE - TARGET ANGLE) + BALANCE KD * CONTROL RATE`。D 项使用陀螺仪 °/s，因此现有 Kp/Kd 不按周期缩放，已调好的参数和 Flash 存档继续使用。
- 摄像头现在朝向原车尾；新左轮使用原右轮 PWM3/4 与编码器 H7，新右轮使用原左轮 PWM1/2 与编码器 H4。IMU 轴向和 RUN 直立反馈不变；FOLLOW 启动不附加前倾角（0°），正常速度环保持原样。
- 编码器每 2 ms 读取，每 10 次形成一个 20 ms 窗口。新前进方向两轮计数均为正。按各轮的一圈标定计数和 6.5 cm 轮径换算车速，左右轮速度取平均值并以 0.25 权重低通；旧编码器 V1 存档在加载时交换左右每转计数。速度环周期、增益和指令斜坡保持原值。
- 速度 PI 每 20 ms 更新：误差为目标车速减滤波车速，正误差调低目标倾角以产生新前进方向的正 PWM，负误差反向修正。RUN 目标为 0 m/s；`FOLLOW START` 立即停机，保持 STOP 2 秒，等待 RUN 实际启动后再保持零速直立 2 秒，同时启用循迹差速。随后按原速度目标进入正常 FOLLOW，不附加启动前倾；原阶段计时保留，循迹差速持续有效，机械中值及 Flash 存档不变。STOP 和 FOLLOW STOP 清除整个启动流程。速度目标仍以 1 m/s² 升至菜单设定值（默认 1.5 m/s）。
- 摄像头直弯 PD 直接产生左右 PWM 差速。直立环保留原始 PD 输出，按硬件 ±10000 PWM 的剩余空间分配差速；最终电机占空比仍限定为 0～100%。
- 速度 PI 的目标倾角修正限于 ±5°，每 20 ms 最多变化 0.04°（2°/s）。新有效图像更新差速；丢线或图像超过 120 ms 时差速清零、速度目标平滑回零。`FOLLOW STOP` 保留 RUN 的零速闭环；`STOP` 关闭电机并清空积分。
- 新右轮按 `BOARD_BALANCE_RIGHT_PWM_TRIM` 减少 PWM，补偿机械差异；电机测试保持原始 PWM。


## IMU 标定

IMU 零偏记录独立保存在 DFlash 第 10 页，不随四档直立参数切换。记录包含三轴陀螺零偏、重力轴、重力方向、魔数、版本及校验值。

首次使用或记录校验失败时，菜单显示 `CALREQ`，RUN 被禁止：

1. 将车保持预期直立姿态，在 IMU 页面执行 `IMU CALIBRATE`。
2. 先连续静止 0.5 秒，再连续收集 2500 个 2 ms 样本，共 5 秒。
3. 中途晃动会丢弃当前窗口并重新等待静止。
4. 重力轴、方向和零偏检查通过后，在主循环自动写入第 10 页；写入期间电机保持关闭。

后续上电从 Flash 加载标定，只预热 100 帧（约 200 ms）并用平均加速度角初始化互补滤波。停机静止 1 秒后允许以约 0.00040012 的系数在 RAM 中慢速修正温漂，保持原来的修正时间常数；RUN、FOLLOW 和电机测试期间不会学习，也不会自动反复写 Flash。

2 ms 是 500 Hz 更新频率，不等于闭环带宽。PIT 的执行时间与迟到检查按 2 ms 适配；实车查看 `CONTROL PERIOD MS`、实际中断周期和最大耗时，确认一次控制计算能在 2000 μs 内完成。FOLLOW 的停机等待、RUN 直立保持和前倾保持各为 2 秒，前后渐变各为 300 ms。

## 菜单与存档

- BALANCE：`BALANCE KP/KD`、`MIDDLE ANGLE`、`ACC WEIGHT KA`、速度 `KP/KI/ANGLE LIMIT`，以及目标/实测速度、速度误差、积分、目标倾角和实际 PWM。
- RUN CONTROL：`TARGET SPEED M/S`（0～3 m/s）、`SPEED ENABLE` 和 `FOLLOW ACTIVE`。正的速度目标对应前进；速度环调整的是小幅目标倾角，不直接叠加 PWM。
- BALANCE 页的 `CAL LEFT 1 REV`、`CAL RIGHT 1 REV` 各按两次：第一次开始记录，手动按前进方向转该轮一圈，第二次结束。两轮完成后自动保存各自每转计数到独立的 DFlash 第 11 页；一圈标定不随四档切换。
- STEERING：直线/弯道 `KP/KD`、方差切换阈值、`TURN PWM LIMIT`、`TURN DIRECTION` 和实际差速。`TURN PWM LIMIT` 默认值为 `1400 PWM`。
- IMU：手动标定、Flash 有效状态、标定来源、静止/微调状态、原始三轴数据和零偏。

四档直立参数存档版本为 V10。V1～V9 加载时保留原有直立、机械中值、输出限幅和方向参数；旧 `FOLLOW SPEED` 是开环角度指令，不转换为 m/s。新速度目标默认 1.5 m/s，FOLLOW 进入 LEAN_IN 后按权重参与目标角，渐变结束后完全恢复为正常速度环目标。旧左右死区以及循迹参数中的 `BASE SPEED/CURVE SLOW` 仅保留 Flash 布局兼容，不参与活动控制。

`BALANCE KP/KD` 不设置人为调参上限，但仍要求有限且非负。直立环不再使用可调 PWM LIMIT，旧字段仅保留 Flash 布局兼容；有限数检查和硬件 ±10000（100% 占空比）边界继续有效。

## 编码器串口采样

打印的左右按原理图连接器标签：左编码器 P02.6/P02.7，右编码器 P20.3/P20.0；控制内部仍按摄像头朝向命名，不改变采样引脚、计数方向或标定数据。

每 100 ms 在主循环通过已重定向的 `printf` 发一行：`左计数,右计数,原始速度x100,滤波速度x100`。计数取最近完成的 20 ms 窗口，不是累计 100 ms 的计数。速度单位为 m/s，发送前乘 100 并截断成整数，例如 `20,30,25,6` 表示左右计数为 20/30，原始速度 0.25 m/s，滤波速度 0.06 m/s。没有编码器标定时计数仍正常发送，速度字段为 0；关闭速度环不影响测速。待机、停机及等待 IMU 标定时继续发送，打开 UART 图像传输时暂停文本发送。

现有调试串口配置为 UART2，TX=P10.5、RX=P10.6，115200 波特率；串口重定向保持原样。FOLLOW 直道的实际前瞻从 `PRE-SIGHT ROW` 起，双轮平均计数/20 ms 超过 250 后每增加 20 减一行，减速时恢复，弯道保持当前行；最低为第 3 行。这一规则与串口前两列计数的单位一致，不依赖每转标定或 m/s 速度字段。

## 静态验证

`node tests/control_numeric.cjs` 执行源码及数值检查，不调用固件编译器。实车先架空确认新左/右轮归属、新前进方向两轮计数均为正，再从低目标速度开始逐步调向 1.5 m/s，观察速度误差、速度角及 PWM 是否收敛。平均速度环不单独校正左右轮速差；目标速度也不能突破电机与 100% 占空比的物理能力。
