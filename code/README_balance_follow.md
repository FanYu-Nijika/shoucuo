# 双轮直立、编码器稳速与摄像头循迹

## 控制链路

- ICM42688 每 5 ms 更新一次。加速度角由当前 X/Z 轴配置计算，俯仰角速度使用扣除标定零偏后的 Y 轴。
- 姿态采用互补滤波：`angle = Ka * accel_angle + (1 - Ka) * (last_angle + gyro_rate * 0.005)`。`ACC WEIGHT KA` 默认 0.01。
- 直立控制每 5 ms 使用直接 PD：`PWM = BALANCE KP * (COMP ANGLE - TARGET ANGLE) + BALANCE KD * CONTROL RATE`，不再对 FOLLOW 的 P 项单独施加 60% 限幅。
- 摄像头现在朝向原车尾；新左轮使用原右轮 PWM3/4 与编码器 H7，新右轮使用原左轮 PWM1/2 与编码器 H4。IMU 轴向和 RUN 直立反馈不变，新车头前倾时 `COMP ANGLE` 增大。
- 编码器每 5 ms 读取、每 20 ms 累计左右计数。新前进方向两轮计数均为正。按各轮的一圈标定计数和 6.5 cm 轮径换算车速，左右轮速度取平均值并以 0.25 权重低通；旧编码器 V1 存档在加载时交换左右每转计数。
- 速度 PI 每 20 ms 更新：误差为目标车速减滤波车速，正误差调低目标倾角以产生新前进方向的正 PWM，负误差反向修正。RUN 目标为 0 m/s；`FOLLOW START` 先请求 RUN，直立真正启动并等待 2 秒后，把目标以 1 m/s² 升至菜单设定值（默认 1.5 m/s）。
- 摄像头直弯 PD 直接产生左右 PWM 差速。直立环保留原始 PD 输出，按硬件 ±10000 PWM 的剩余空间分配差速；最终电机占空比仍限定为 0～100%。
- 速度 PI 的目标倾角修正限于 ±5°，每 20 ms 最多变化 0.04°（2°/s）。新有效图像更新差速；丢线或图像超过 120 ms 时差速清零、速度目标平滑回零。`FOLLOW STOP` 保留 RUN 的零速闭环；`STOP` 关闭电机并清空积分。
- 新右轮按 `BOARD_BALANCE_RIGHT_PWM_TRIM` 减少 PWM，补偿机械差异；电机测试保持原始 PWM。


## IMU 标定

IMU 零偏记录独立保存在 DFlash 第 10 页，不随四档直立参数切换。记录包含三轴陀螺零偏、重力轴、重力方向、魔数、版本及校验值。

首次使用或记录校验失败时，菜单显示 `CALREQ`，RUN 被禁止：

1. 将车保持预期直立姿态，在 IMU 页面执行 `IMU CALIBRATE`。
2. 先连续静止 0.5 秒，再连续收集 1000 个 5 ms 样本，共 5 秒。
3. 中途晃动会丢弃当前窗口并重新等待静止。
4. 重力轴、方向和零偏检查通过后，在主循环自动写入第 10 页；写入期间电机保持关闭。

后续上电从 Flash 加载标定，只预热 40 帧（约 200 ms）并用平均加速度角初始化互补滤波。停机静止 1 秒后允许以 0.001 的系数在 RAM 中慢速修正温漂；RUN、FOLLOW 和电机测试期间不会学习，也不会自动反复写 Flash。

## 菜单与存档

- BALANCE：`BALANCE KP/KD`、`MIDDLE ANGLE`、`ACC WEIGHT KA`、速度 `KP/KI/ANGLE LIMIT`，以及目标/实测速度、速度误差、积分、目标倾角和实际 PWM。
- RUN CONTROL：`TARGET SPEED M/S`（0～3 m/s）、`SPEED ENABLE` 和 `FOLLOW ACTIVE`。正的速度目标对应前进；速度环调整的是小幅目标倾角，不直接叠加 PWM。
- BALANCE 页的 `CAL LEFT 1 REV`、`CAL RIGHT 1 REV` 各按两次：第一次开始记录，手动按前进方向转该轮一圈，第二次结束。两轮完成后自动保存各自每转计数到独立的 DFlash 第 11 页；一圈标定不随四档切换。
- STEERING：直线/弯道 `KP/KD`、方差切换阈值、`TURN PWM LIMIT`、`TURN DIRECTION` 和实际差速。`TURN PWM LIMIT` 默认值为 `1400 PWM`。
- IMU：手动标定、Flash 有效状态、标定来源、静止/微调状态、原始三轴数据和零偏。

四档直立参数存档版本为 V10。V1～V9 加载时保留原有直立、机械中值、输出限幅和方向参数；旧 `FOLLOW SPEED` 是开环角度指令，不转换为 m/s。新速度目标默认 1.5 m/s，只有 FOLLOW 启动并完成等待后才生效。旧左右死区以及循迹参数中的 `BASE SPEED/CURVE SLOW` 仅保留 Flash 布局兼容，不参与活动控制。

`BALANCE KP/KD` 不设置人为调参上限，但仍要求有限且非负。直立环不再使用可调 PWM LIMIT，旧字段仅保留 Flash 布局兼容；有限数检查和硬件 ±10000（100% 占空比）边界继续有效。

## 静态验证

`node tests/control_numeric.cjs` 执行源码及数值检查，不调用固件编译器。实车先架空确认新左/右轮归属、新前进方向两轮计数均为正，再从低目标速度开始逐步调向 1.5 m/s，观察速度误差、速度角及 PWM 是否收敛。平均速度环不单独校正左右轮速差；目标速度也不能突破电机与 100% 占空比的物理能力。
