# 双轮直立、编码器稳速与摄像头循迹

## 控制链路

- 当前按镜头相对上一次安装转向 180°、保持图像正立且主板/IMU/接线不动适配。正的 `TARGET SPEED M/S` 表示朝镜头的新前方行驶，对应负共模 PWM；控制左编码器符号为 -1，右编码器为 +1，新前进方向两路计数及速度均为正。速度不足时目标倾角修正为负，超速时修正为正。IMU 轴、机械中值、直立 PD、电机通道和已校正的差速符号保留。
- LEFT/RIGHT 继续作为固定硬件通道名使用，转向以镜头画面为准。每轮每转计数是同一物理轮的标定值，反向不交换 V2 标定、不修改四档 Flash 增益；动态前瞻继续使用新的正向平均计数。电机测试仍输出原始有符号 PWM，新前进对应负测试值。
- ICM42688 每 2 ms 读取一次，传感器输出率为 1 kHz。加速度角由当前 X/Z 轴配置计算，俯仰角速度使用扣除标定零偏后的 Y 轴。
- 姿态采用互补滤波：`angle = Ka_effective * accel_angle + (1 - Ka_effective) * (last_angle + gyro_rate * 0.002)`。菜单与 Flash 的 `ACC WEIGHT KA` 保留原 5 ms 定义，应用参数时换算为 `Ka_effective = 1 - (1 - Ka)^0.4`；原值 0.01 对应约 0.004012，保持滤波时间常数，换算不在每次中断里执行。
- 直立控制每 2 ms 使用直接 PD：`PWM = -(BALANCE KP * (COMP ANGLE - TARGET ANGLE) + BALANCE KD * CONTROL RATE)`。当前 IMU 安装方向需要将 PD 总输出反号；D 项使用陀螺仪 °/s，现有 Kp/Kd、机械中值和 Flash 存档继续使用。
- 电机固定通道 LEFT 使用 PWM1/2，RIGHT 使用 PWM3/4。每组偶数路输出正 PWM、奇数路输出负 PWM，左右电机方向符号均为 +1；菜单测试和平衡控制共用此映射。编码器仍为 LEFT=H7、RIGHT=H4，各轮 Flash 标定归属保持原样。`BOARD_FOLLOW_TURN_PWM_SIGN` 保留已实车校正的 -1；镜头水平转向 180°且轮通道不换时，右转对应的物理偏航方向不变。
- 编码器每 2 ms 读取并立即发布左右增量，以 `速度 = 轮周长 × (左增量/左每转计数 + 右增量/右每转计数) / (2 × 0.002)` 换算 m/s。LEFT/H7 采样符号为 -1，RIGHT/H4 为 +1，使新的前进方向两轮计数为正；计数幅值不缩放。按各轮的一圈标定计数和 6.5 cm 轮径换算车速，左右轮速度取平均值，每 2 ms 按 `filtered = 0.9 * raw + 0.1 * last_filtered` 低通，让当前速度占 90%；视觉前瞻的平均计数单独保留 20 ms 累计窗口；旧编码器 V1 存档仍按原迁移规则加载，V2 标定不交换。速度环周期和原有增益继续使用。
- 速度 PI 每 20 ms 更新：使用直接 PI：`error = target - speed`，`I = clamp(I + Ki * error * 0.02, ANGLE LIMIT)`，`angle = FORWARD SIGN * clamp(Kp * error + I, ANGLE LIMIT)`；误差为当前请求车速减滤波车速，正误差降低目标倾角，经反号后的直立 PD 产生新前进方向的负 PWM，负误差反向修正。普通 RUN 关闭速度环，只使用直立 PD。`FOLLOW START` 立即停机，保持 STOP 2 秒，等待 RUN 实际启动后再直立保持 2 秒，此阶段速度环关闭，循迹差速沿用原行为。直立结束进入 LEAN_IN（第一循迹阶段）时才启用速度 PI，按菜单速度目标运行，不附加启动前倾；原阶段计时、机械中值及 Flash 存档不变。STOP 和 FOLLOW STOP 清除整个启动流程及速度积分、倾角修正。速度目标直接使用当前请求值（FOLLOW 默认 1.5 m/s），取消目标速度斜坡、倾角输出变化速率限制和按电机饱和拒绝积分的额外条件。
- 摄像头直弯 PD 直接产生左右 PWM 差速。转向差速按校正后的方向分配，直立共模输出保持原样；按硬件 ±10000 PWM 的剩余空间分配差速，最终占空比允许 0～100%，电机测试恢复同一硬件范围。原有 Flash 参数和 `TURN PWM LIMIT` 继续使用。
- 速度 PI 的目标倾角修正默认限于 ±5°，可调到 ±20°，每次 PI 更新直接应用限幅后的输出。新有效图像更新差速；丢线或图像超过 120 ms 时只清零差速，循迹速度目标继续使用菜单设定值，不产生零速制动跳变。`FOLLOW STOP` 关闭速度环，保留 RUN 的直立 PD；`STOP` 关闭电机并清空积分。
- 新右轮按 `BOARD_BALANCE_RIGHT_PWM_TRIM` 减少 PWM，补偿机械差异；电机测试保持原始 PWM。


## IMU 标定

IMU 零偏记录独立保存在 DFlash 第 10 页，不随四档直立参数切换。记录包含三轴陀螺零偏、重力轴、重力方向、魔数、版本及校验值。

首次使用或记录校验失败时，菜单显示 `CALREQ`，RUN 被禁止：

1. 将车保持预期直立姿态，在 IMU 页面执行 `IMU CALIBRATE`。
2. 先连续静止 0.5 秒，再连续收集 2500 个 2 ms 样本，共 5 秒。
3. 中途晃动会丢弃当前窗口并重新等待静止。
4. 重力轴、方向和零偏检查通过后，在主循环自动写入第 10 页；写入期间电机保持关闭。

后续上电从 Flash 加载标定，只预热 100 帧（约 200 ms）并用平均加速度角初始化互补滤波。停机静止 1 秒后允许以约 0.00040012 的系数在 RAM 中慢速修正温漂，保持原来的修正时间常数；RUN、FOLLOW 和电机测试期间不会学习，也不会自动反复写 Flash。

编码器测速与直立 PD 每 2 ms 更新（500 Hz），速度 PI 每 20 ms 更新（50 Hz），其积分使用 0.02 s，不对速度目标或 PI 倾角输出施加斜坡。20 ms 是更新周期，不是带宽；串级要求直立内环响应比速度外环快，真实带宽须根据实车响应确定。PIT 的执行时间与迟到检查按 2 ms 适配；实车查看 `CONTROL PERIOD MS`、实际中断周期和最大耗时，确认一次控制计算能在 2000 μs 内完成。FOLLOW 的停机等待、RUN 直立保持和前倾保持各为 2 秒，前后渐变各为 300 ms。

## 菜单与存档

- SPEED：主菜单中位于 STEERING 上方，首先显示 `SPEED KP/KI/ANGLE LIMIT`、目标速度和开关；速度诊断、左右 2 ms 计数及一圈标定也集中在此页。Kp/Ki 继续允许负数。
- BALANCE：`BALANCE KP/KD`、`MIDDLE ANGLE`、`ACC WEIGHT KA`、目标/实际倾角和直立输出。
- RUN CONTROL：`TARGET SPEED M/S`（0～3 m/s）、`SPEED ENABLE` 和 `FOLLOW ACTIVE`。正的速度目标对应前进；速度环调整的是小幅目标倾角，不直接叠加 PWM。
- SPEED 页的 `CAL LEFT 1 REV`、`CAL RIGHT 1 REV` 各按两次：停机后第一次开始记录，手动转该轮整整一圈，第二次结束，正反方向均可。两轮完成后自动保存各自每转计数到独立的 DFlash 第 11 页；一圈标定不随四档切换。
- STEERING：直线/弯道 `KP/KD`、方差切换阈值、`TURN PWM LIMIT`、`TURN DIRECTION` 和实际差速。`TURN PWM LIMIT` 默认值为 `1400 PWM`。
- IMU：手动标定、Flash 有效状态、标定来源、静止/微调状态、原始三轴数据和零偏。

四档直立参数存档版本为 V10。V1～V9 加载时保留原有直立、机械中值、输出限幅和方向参数；旧 `FOLLOW SPEED` 是开环角度指令，不转换为 m/s。新速度目标默认 1.5 m/s，FOLLOW 进入 LEAN_IN 后速度环直接参与目标角。`SPEED ENABLE` 是循迹速度环总开关；即使为 ON，普通 RUN 和 FOLLOW 直立阶段仍关闭速度环。旧左右死区以及循迹参数中的 `BASE SPEED/CURVE SLOW` 仅保留 Flash 布局兼容，不参与活动控制。

直立、速度、直道和弯道转向的控制增益均不设置人为调参上限，菜单使用浮点类型的可表示范围；速度 Kp/Ki 不再受旧的 20/10 校验限制。增益允许正数、零和负数，仅要求数值有限，停止状态下重新应用有效参数且姿态已初始化时，会清除之前的 NUMERR；无效姿态和其他故障继续保留。直立环不再使用可调 PWM LIMIT，旧字段仅保留 Flash 布局兼容；目标倾角限幅和硬件 ±10000（100% 占空比）边界继续有效。

## 速度环 FireWater 串口采样

115200 同步 `printf` 在主循环中以 20 ms 为最小间隔输出一帧 FireWater 数据，共 22 列；主循环调度可能让实际间隔更长，因此日志不是严格 50 Hz。在 VOFA+ 选择 FireWater，并关闭菜单中的 UART 图像传输。第 6 列是主循环采样时的 `now_ms` 毫秒时间戳；用相邻帧时间戳之差判断实际打印间隔。主循环调度不保证每次 2 ms 直立更新或每次 20 ms 速度 PI 更新都恰好被采到。

| 列 | 内容 | 单位 / 格式 |
| --- | --- | --- |
| 0 | 当前速度目标 | m/s |
| 1 | 当前 2 ms 低通速度 | m/s |
| 2 | 已按当前板级方向取反并限幅后的 PI 倾角修正 | 度 |
| 3 | 直立目标角度，包含速度修正 | 度 |
| 4 | 实际姿态角度 | 度 |
| 5 | 限制到硬件范围前的直立共模 PWM | PWM |
| 6 | 主循环采样时间戳 `now_ms` | ms，uint32 |
| 7 | 当前 2 ms 编码器原始速度 | m/s |
| 8 | 最近一次 20 ms PI 更新使用的反馈速度 | m/s |
| 9 | 最近一次 PI 速度误差 | m/s |
| 10 | PI 的 P 倾角分量，限幅和板级方向处理前 | 度 |
| 11 | PI 的 I 倾角分量，已按角度限幅、未乘板级方向 | 度 |
| 12 | 俯仰陀螺仪角速度 | °/s |
| 13 | 转向请求 PWM，已按 `TURN PWM LIMIT` 限幅 | PWM |
| 14 | 实际分配的差速 PWM | PWM |
| 15 | 左轮当前 2 ms 有符号计数 | count/2 ms |
| 16 | 右轮当前 2 ms 有符号计数 | count/2 ms |
| 17 | 左电机实际 PWM | PWM |
| 18 | 右电机实际 PWM | PWM |
| 19 | 速度 PI 本周期是否启用 | 0/1 |
| 20 | 平衡控制是否运行 | 0/1 |
| 21 | 当前故障枚举值 | 整数：0 NONE，1 STOPPED，2 IMU，3 TILT，4 NUMERIC，5 TIMING，6 CALIBRATION |

第 10、11 列的 P/I 分量都没有乘板级方向；当前板级方向为 -1，应用角度等于 `clamp(-(P + I), -ANGLE LIMIT, +ANGLE LIMIT)`。第 19 列为 0 时速度 PI 未运行，第 8、9、10、11 列中的 0 是禁用状态值，不表示实测速度为 0；判断实测速度应看第 1、7 列。未完成编码器标定时，当前 raw 和 filtered 速度为 `nan`，表示未知，不会伪造为 0。

数值列按格式输出：0～4 保留三位小数，5 保留一位，6 为整数，7～11 保留三位，12 保留两位，13～14 为整数格式，15～21 为整数。帧数据先在关中断时复制完整状态，再恢复中断后格式化和打印。停机和待机仍发送；UART 图像传输期间暂停文本，恢复后按 20 ms 最小间隔继续。

调参时先确认第 19 列为 1、第 20 列为 1、第 21 列为 0。比较第 15、16 列和第 7、1、8 列，可检查编码器方向、原始速度、滤波速度及 PI 实际取用速度是否一致；再看第 9、10、11、2 列，确认误差、P/I 分量和最终限幅角度。第 3、4、12 列显示直立目标、实际姿态和陀螺速度响应；第 5、13、14、17、18 列可判断共模输出、转向差速及左右电机输出是否达到限制。调整参数后用时间戳对齐变化，避免把稀疏主循环采样误认为每次 PI 更新记录。

现有调试串口为 UART2，TX=P10.5、RX=P10.6，115200 波特率，串口重定向保持原样。

## 静态验证

`node tests/control_numeric.cjs` 执行源码及数值检查，不调用固件编译器。实车先架空确认新左/右轮归属、新前进方向两轮计数均为正，再从低目标速度开始逐步调向 1.5 m/s，观察速度误差、速度角及 PWM 是否收敛。平均速度环不单独校正左右轮速差；目标速度也不能突破电机与 100% 占空比的物理能力。
