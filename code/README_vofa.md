# VOFA+ 无线调参和波形

车端使用 UART2（P10.5 TX、P10.6 RX）连接逐飞无线串口模块，波特率 115200、8N1。必须先用 AURIX 开发环境编译并烧录本工程的新固件；修改 workspace 源码不会自动更新单片机。无线模块处于普通透传模式时，电脑端在 VOFA+ 选择无线 USB 模块对应的串口和 **FireWater** 协议。本机当前的无线 USB 模块是 `SEEKFREE Wireless Com Port (COM28)`；`COM25` 是 Infineon 调试串口，不能接收 UART2 的无线波形。串口号在重新插拔后可能变化，以设备管理器中的设备名称为准。

逐飞模块排针侧的串口波特率也必须已配置为 115200；本工程使用普通 UART2 透传，没有调用库里的 RTS 自动波特率握手。车端模块 TX 接 P10.6、RX 接 P10.5，并共地。两端蓝灯表示各自正在发送，高频发送时可能看起来常亮；判断车端数据是否到达电脑，重点看无线 USB 模块的绿灯（接收），不要仅凭蓝灯判断已连通。

固件启动时发送 `VOFA READY`，之后每 20 ms 持续发送 `d:` 波形。若 VOFA+ 已连接但看不到启动文字，可复位单片机；若没有持续的 `d:` 数据，先确认已烧录新固件、无线模块配对并处于透传模式、车端 UART2 接线正确。若 VOFA+ 提示串口被占用，关闭其他正在使用该串口的软件。

## 下发参数

在 VOFA+ 的字符串发送区输入命令，并启用换行；每条命令以 `\n` 结束，`\r\n` 也可。命令区分大小写，数值使用英文小数点。可以将以下文本保存为 VOFA+ 命令：

```text
SET BALANCE_KP 1000
SET BALANCE_KD 25.0556
SET MIDDLE_ANGLE 0
SET SPEED_KP 2
SET SPEED_KI 0.3
SET TARGET_SPEED_MPS 1.5
SET SPEED_ANGLE_LIMIT 5
GET
SAVE
```

| 名称 | 含义 | 有效范围 |
| --- | --- | --- |
| `BALANCE_KP` | 角度环比例增益 | 有限且 ≥ 0 |
| `BALANCE_KD` | 角度环微分增益 | 有限且 ≥ 0 |
| `MIDDLE_ANGLE` | 直立中值角，度 | −180～180 |
| `SPEED_KP` | 速度环比例增益 | 0～20 |
| `SPEED_KI` | 速度环积分增益 | 0～10 |
| `TARGET_SPEED_MPS` | FOLLOW 目标速度，m/s | 0～3 |
| `SPEED_ANGLE_LIMIT` | 速度环目标倾角限幅，度 | 0～10 |

`SET` 校验通过后立即生效，包括中值角；目标速度按现有 FOLLOW 控制逻辑使用，RUN 的目标仍为零。`GET` 返回七行 `PARAM <名称> <当前值>`，末尾是 `OK GET`。`SET` 返回 `OK SET <名称> <值>`；格式、名称、数值、范围错误分别返回 `ERR SYNTAX`、`ERR NAME`、`ERR NUMBER`、`ERR RANGE`。一行过长返回 `ERR LINE_TOO_LONG`，串口接收队列溢出返回 `ERR RX_OVERFLOW`。

收到 `ERR RX_OVERFLOW` 后，先发送一个换行让接收端重新对齐，再重发命令。

参数仅在 RAM 中实时生效。停机后发送 `SAVE`，收到 `OK SAVE` 才表示已写入当前档位；运行或准备启动时返回 `ERR RUNNING`，写入失败返回 `ERR SAVE`。可执行 `GET` 核对后重新上电，再执行 `GET` 验证保存值。

## 波形通道

车端每 20 ms 发送一行 `d:` 开头的 FireWater CSV 波形。VOFA+ 将下列顺序的十个数值通道绑定到波形图：

| 通道 | 数据 | 单位 |
| --- | --- | --- |
| 0 | 互补滤波实际角度 | 度 |
| 1 | 目标角度 | 度 |
| 2 | 角度误差 | 度 |
| 3 | 陀螺仪角速度 | 度/秒 |
| 4 | 角度环原始输出 | PWM |
| 5 | 实际采用的速度目标 | m/s |
| 6 | 滤波后的实测速度 | m/s |
| 7 | 速度误差 | m/s |
| 8 | 速度环倾角修正 | 度 |
| 9 | 左右轮共同 PWM | PWM |

`OK`、`ERR`、`PARAM` 是文本回执，不是波形数据。调试时先架空车轮核对增益、角度和方向，再在实车上逐步调节。
