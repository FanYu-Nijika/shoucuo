#### 摄像头特点

1. **FPS可调**：帧数可在0~500帧以内随意切换，并且在此范围内的图像均很稳定(注意:752X480像素时分辨率最大为60FPS，80X60像素时分辨率最大为498FPS)
2. **可自动曝光**：总钻风具有自动曝光功能，当环境变亮摄像头会自动减小曝光时间，当环境变暗摄像头会自动增加曝光时间。这样摄像头就可以使用不同的环境
3. **曝光时间随时可调(当自动曝光关闭时)**：当摄像头采集到图像较亮(曝光过度)时，可以通过程序去调节曝光时间，使得图像不那么亮，而且改变曝光时间不需要复位摄像头
4. **用户不用自己写驱动程序**：总钻风摄像头内部集成了驱动装置芯片，所以用户不需要自己写摄像头驱动程序
